# Worth It? — test build

Temporary, public-ish test site so the app can be tried on a phone.

**This is not a real valuation tool.** Reference prices are invented placeholders, not live market data. Do not use the scores to buy or sell a car.

Intended test URL: https://ethanjramsey-cyber.github.io/worth-it-test/

The site is set to `noindex,nofollow`. It is still a public GitHub Pages site on a public repository, so anyone with the link can open it.

## Take it down

- Disable GitHub Pages in the repository settings (Settings → Pages), or
- Delete this repository (`ethanjramsey-cyber/worth-it-test`)
