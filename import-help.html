Worth It? import

  1. Open the used-car listing in your browser (Autotrader, Gumtree, eBay, Facebook Marketplace, CarGurus, Motors.co.uk, Cinch…).
  2. Tap or click the Worth It? import bookmark.
  3. This app opens on the “Is this right?” screen, with any details the page made available already filled in. Missing boxes are highlighted so you can complete them — nothing is guessed.

If the host changes, come back to this page and drag the bookmark again so it points at the new address.

Paste the listing text

Copy the heading and specs from the advert — for example:

2018 (68 reg) Ford Fiesta 1.0 EcoBoost 125 Titanium 5dr
42,000 miles, Petrol, Manual, £8,495

Then paste that into the checker. Year, mileage, fuel, engine, gearbox and price are filled when they’re obvious. Anything unclear is left blank.

Paste a listing link

A local lookup can read structured data from some dealer pages (Cinch worked in our tests). Sites that refuse a simple request, or that only fill in after JavaScript in your browser, won’t work from a pasted link — use the bookmarklet or paste the text instead.

The lookup is off unless a local worker URL is set. Nothing here is deployed.
